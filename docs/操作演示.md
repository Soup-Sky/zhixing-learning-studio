# 操作演示

## 演示环境

- Windows 10/11，Edge 或 Chrome。
- 知行 1.3.1 Windows 免安装包，或源码方式 `start.cmd` / `./start.sh`。
- 管理员账号已创建，DeepSeek API Key 已在“设置与账号”验证并保存。
- 建议提前准备一门“单变量微积分”课程，减少现场生成等待。

## 演示顺序（约 5 分钟）

### 1. 启动与登录

双击 `ZhixingLearningStudio.exe`，浏览器打开 `http://127.0.0.1:8877/`。

讲解点：服务只监听本机、无控制台窗口、再次双击只重新打开页面。首次使用创建管理员账号。

### 2. 新建主题

点击“新建主题”，填写：

- 主题：单变量微积分
- 已有基础：学过高中数学
- 学习目标：掌握极限与导数基础
- 每周时间：3 小时
- 每次时长：30 分钟

点击“创建学习路径”。讲解点：主题、基础、目标和时间进入建课参数，不是直接给一套统一内容。

### 3. 起点测评

进入课程后，左侧是知识地图。完成 3 道起点测评题并提交。

讲解点：未测单元显示“未知”，不会被当作已掌握；前测结果决定后续计划与先修补齐。

### 4. 计划、讲义与练习

打开“学习计划”“讲义”“练习”：

- 计划显示单元顺序、每单元时长、重点和先修关系。
- 讲义包含知识讲解、例题、易错点、来源引用，公式由 KaTeX 渲染。
- 练习按当前单元生成，附量规和三级提示，提交前不展示参考答案。

### 5. 提交练习与反馈

故意提交一个错误答案，展示：

- 逐题得分与错误定位。
- 参考答案、核验依据和 AI 审核建议。
- “对本题评分有疑问”申诉入口（每题一次，原分保留）。
- “补讲与新练习”按钮：未达 80% 时生成针对性补讲。

### 6. 教师审核与进度

打开左侧“教师审核”：

- 查看 AI 标记“建议核对”的记录，显示学生答案、参考答案、AI 建议和原分。
- 修改分数并提交，系统重新计算该单元掌握度。
- 打开“学员进度”，查看掌握单元、练习次数、平均分和待复习错题（不显示作答内容）。
- 在“设置与账号”底部演示“退出程序”。

## 讲解主线

1. **学习闭环**：前测影响计划，练习影响掌握度，反馈影响补讲与推进。
2. **规则约束**：知识图谱控制顺序，SymPy 核验表达式，AI 审核标注不确定项。
3. **教师治理**：AI 先审、教师可改；原分保留，改分后重算掌握度。
4. **完整交付**：学生端、教师端、多账号、备份、日志与 Windows 免安装包。

## 异常处理

- 模型服务不可用：页面显示失败原因，已保存记录不受影响；可改用已保存课程继续演示。
- 8877 端口被占用：关闭占用程序后重启；源码方式可用 `--port` 换端口。
- 演示机未配置密钥：先由管理员在设置页填写并验证，不在演示中展示密钥内容。
