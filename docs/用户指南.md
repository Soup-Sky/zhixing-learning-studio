# 知行用户指南（1.3.1）

## 一、启动

### Windows 免安装包

1. 解压整个 ZIP 文件夹，双击 `ZhixingLearningStudio.exe`。不要只复制 EXE。
2. 程序没有启动窗口，会直接在浏览器打开 `http://127.0.0.1:8877/`。
3. 再次双击只会重新打开页面；要完全退出，由管理员在“设置与账号”底部点击“退出程序”。

### 源码方式

Windows：

```powershell
.\start.cmd
```

macOS / Linux：

```bash
./start.sh
```

需要 Python 3.11+。前端构建产物已随仓库提供；只有修改前端源码后重建时才需要 Node.js 20+。

默认数据库：源码方式为 `data/learning.sqlite`；Windows 免安装包为 `%LOCALAPPDATA%\ZhixingLearningStudio\learning.sqlite`。可在启动时用 `--db` 或环境变量 `LEARNING_DB` 指定其他位置。

## 二、账号

- 第一个创建的账号是管理员，可以添加、停用、删除账号，重置他人密码，设置 DeepSeek 密钥。
- 各账号的课程、错题本、资料和测验互不可见。
- 管理员可以查看学员进度（只有统计，不含作答内容）、下载数据库备份、查看脱敏错误日志。
- 忘记管理员密码：
  - Windows 免安装包：在程序目录运行 `ZhixingLearningStudio.exe --reset-password 用户名`，弹窗显示临时密码。
  - 源码方式：`.\.venv\Scripts\python.exe desktop.py --reset-password 用户名 data\learning.sqlite`。

## 三、配置 DeepSeek 密钥

1. 用管理员账号登录，进入“设置与账号”。
2. 粘贴 DeepSeek 官方 API Key，点击“验证并保存”。
3. Windows 可勾选“记住密钥”，保存到 Windows 凭据管理器；不勾选则仅本次运行有效。
4. macOS / Linux 只保存在进程内存，重启后需重新填写。

DeepSeek 拒绝的密钥不会保存。密钥不会写入数据库、课程记录、日志或截图。请自行确认账号余额，软件不会自动充值。

## 四、学习

1. 点击“新建主题”，填写主题、已有基础、学习目标、每周可投入时间和每次时长；可勾选自己上传的资料。
2. 完成起点测评。未测单元保持“未知”，系统依据实际作答生成学习计划。
3. 阅读讲义，完成练习；提交后查看逐题得分、错因、参考答案与核验依据。
4. 未达 80% 时可点击“补讲与新练习”，系统针对错因重新讲解。
5. 对某题评分有疑问：在反馈里点击“对本题评分有疑问”，写明理由；AI 会重新批改该题，每题一次，原分保留可见。
6. 得分低于 80% 的题进入错题本，按 1、3、7 天安排复习。
7. 12 单元微积分课程提供“阶段测验”（前测、后测、延迟测），固定题，不计入日常练习。
8. 划选讲义文字可以向学习助手提问，按提示层级逐步给思路。

## 五、教师与管理

- **教师审核**：列出 AI 标记“建议核对”的记录，显示学生答案、参考答案、AI 建议和原分；可确认或改分。改分后重新计算掌握度。
- **学员进度**：各账号的掌握单元、练习次数、平均分、待复习错题和模型用量，不显示作答与对话。
- **账号管理**：添加、停用、删除账号，重置密码，设置角色。
- **数据管理**：下载 SQLite 备份、查看错误日志、退出程序。

## 六、数据与备份

- 学习数据保存在本机 SQLite 文件；所有知行账号共用同一个文件。
- 备份：管理员在“关于与数据”里点击“下载备份”，得到一个 `.sqlite` 文件；也可以先退出程序，再复制整个数据目录。
- 恢复：退出程序后，删除同目录的 `learning.sqlite-wal`、`learning.sqlite-shm`（如果有），把备份文件改名为 `learning.sqlite` 替换原文件。
- 错误日志位于数据目录的 `logs/errors.log`，密钥会被替换为 `[REDACTED]`。
- 90 天未打开且无新学习记录的课程会在启动时清理；内置教材和用户上传资料保留到手动删除。

## 七、卸载

1. 先由管理员在网页中退出程序。
2. 删除解压目录。
3. 如需移除个人学习记录，删除 `%LOCALAPPDATA%\ZhixingLearningStudio` 目录。
4. 保存的密钥可先在设置页清除，或在 Windows 凭据管理器中删除 `ZhixingLearningStudio/DeepSeek`。

## 八、常见问题

**页面打不开？**

确认程序已启动、8877 端口未被占用。源码方式可换端口：`python scripts/serve.py --port 8899`。

**提示“尚未配置 DeepSeek API Key”？**

用管理员账号在“设置与账号”里填写并验证 Key。

**没有 Node.js 能运行吗？**

可以。仓库已包含 `frontend/dist`；只有修改前端源码后重建时才需要 Node.js 20+。

**macOS / Linux 能记住密钥吗？**

当前“记住密钥”使用 Windows 凭据管理器；macOS / Linux 只保存在进程内存。

**模型调用失败会怎样？**

页面显示失败原因，已保存的学习记录不受影响；不会用模拟教学替代真实生成。
